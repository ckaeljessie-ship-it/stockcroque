🏷️ Générer des codes-barres

Chaque sac reçoit un code unique : CODE PRODUIT / NUMÉRO (ex : GM20/01, GM20/02…).

Ex : « Du n° 3 au n° 5 » pour GM20 donne GM20/03, GM20/04, GM20/05. Rien n'est ajouté au stock.

Aperçu

Code-barres imprimé en 4,5 cm de large. Dans la fenêtre d'impression, garde l'échelle à 100 % (pas « Ajuster à la page »).

Colle une étiquette sur chaque sac. Si tu as décoché « Ajouter directement ces sacs au stock », scanne ensuite chaque sac en mode Entrée pour l'ajouter.

✏️ Modifier un produit

Le code court ne change pas : les étiquettes déjà collées restent valables. Suppression possible seulement si le stock est à 0.

À utiliser si le compteur d'un produit ne correspond plus aux sacs codés (anciennes sorties manuelles).

⚠️ Zone dangereuse

Les codes-barres déjà imprimés restent valides (ils redeviennent « non utilisés »).
